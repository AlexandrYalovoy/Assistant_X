# Установка Assistant X — инструкция для ИИ-агента

<!-- Made by assistant-x gen-docs from assistant_x/templates/docs/INSTALL_FOR_AI.ru.md: edit that file. -->

Вы — агент (Codex, Claude Code, DeepSeek Harness или другой, который умеет запускать команды), и пользователь попросил
установить или подключить **Assistant X**: локальную библиотеку его документов (PDF, DOC/DOCX, PPTX, сканы) с поиском
по словам и по смыслу, которую ИИ-приложения получают по MCP. Выполняйте шаги по порядку. Каждую команду запускайте
только после согласия пользователя и одной строкой говорите, что она делает. Эта инструкция относится к версии
{{version}}; устанавливайте всегда **последний выпуск**: {{latest}}.

## 1. Расскажите пользователю, что будет, и спросите

- Загрузки: исходники выпуска (≈ 5 МБ), пакеты Python (≈ 1 ГБ; ≈ 3,5 ГБ со сборкой torch для CUDA, если видеокарта
  NVIDIA), модели поиска по смыслу (≈ 4,5 ГБ, по желанию: без них поиск идёт только по словам).
- Папки: программа и модели — в `%USERPROFILE%\.assistant_x` (Linux: `~/.cache/AssistantX`; установку до 0.5.1 в
  `%LOCALAPPDATA%\AssistantX` программа заберёт сама); данные пользователя — в одной рабочей папке, по умолчанию
  `Documents\Assistant X`. Спросите, нужна ли другая папка, и профиль: `general` (любая область, по умолчанию) или
  `oil-gas-ru` (русскоязычный инженер-технолог нефтегазовой отрасли).
- Приватность: библиотека и поиск остаются на ПК; страницы, которые модель читает для ответа, уходят поставщику
  модели приложения (с локальной моделью в LM Studio ничего не покидает ПК).

## 2. Python 3.11

`py -3.11 -V` (Windows) или `python3.11 -V` (Linux). Если его нет: в Windows `winget install -e --id Python.Python.3.11`
(после «да» пользователя), в Linux — пакет системы.

## 3. Последний выпуск

Узнайте тег последнего выпуска (`vX.Y.Z`) на {{latest}} (или через GitHub API
`https://api.github.com/repos/AlexandrYalovoy/Assistant_X/releases/latest`, поле `tag_name`). Из файлов этого выпуска
скачайте `assistant_x-<version>-src.zip` и `SHA256SUMS.txt` (`{{repo}}/releases/download/<tag>/<file>`; `<version>` —
это тег без `v`) и прежде всего проверьте архив: его SHA-256 (`Get-FileHash -Algorithm SHA256 FILE` в Windows,
`sha256sum FILE` в Linux) должен совпасть с указанным в `SHA256SUMS.txt`; если не совпадает, остановитесь и скажите
пользователю. Распакуйте архив в `%USERPROFILE%\.assistant_x\src\<tag>` (Linux: `~/.cache/AssistantX/src/<tag>`):
программа устанавливается из этой папки и продолжает ею пользоваться, поэтому не кладите её в «Загрузки» или во
временную папку. (У выпусков до 0.5.3 исходного архива среди файлов нет: используйте
`{{repo}}/archive/refs/tags/<tag>.zip`.)

## 4. Установка

В этой папке:

```
py -3.11 -m assistant_x.setup.install --online --yes --json [--workspace "D:\My library"] [--profile oil-gas-ru]
```

(В Linux — `python3.11`.) Команда создаёт окружение `%USERPROFILE%\.assistant_x\venv`, ставит пакеты, создаёт рабочую
папку, подключает все найденные приложения и проверяет себя; ничего не спрашивает (`--yes`). Её последняя строка —
один объект JSON: `ok`, `version`, `python`, `command` (программа `assistant-x`), `workspace`, `device`, `apps`
(подключённые), `problems`, `next`. Перескажите пользователю `problems` простыми словами. После сбоя запустите её
снова: сделанное повторно не делается. `--dry-run` показывает, что она сделала бы.

## 5. Модели (по желанию, ≈ 4,5 ГБ)

После «да» пользователя: `<command> download-models` (`command` из JSON). Без моделей поиск идёт только по словам.

## 6. Подключите приложения и проверьте

`<command> connect auto` подключает все приложения, найденные на этом ПК ({{apps}}); `<command> connect APP` — одно
приложение. Установщик это уже сделал; запустите снова, если приложение поставили позже. Затем
`<command> connect --check`: рукопожатие и поиск через запись каждого приложения. Каждое приложение нужно
перезапустить (Claude Desktop: значок у часов → Quit), кроме DeepSeek Harness и LM Studio, которые перечитывают
настройки сами. Для Claude Desktop пользователь ещё загружает навык: `<command> skill`, затем заархивировать в zip
названную папку и загрузить её в Settings → Capabilities → Skills.

## 7. Базовый пакет (если у пользователя есть файл `.axbase`)

`<command> base inspect FILE` показывает, что в пакете, и вопросы; покажите их пользователю. Только после его явного
«да»: `<command> base install FILE --confirm` (с `--keep own|package`, если проверка спросила, чьи шифры сохранять).

## 8. Расскажите пользователю, как пользоваться

- В любом подключённом приложении: начните сообщение с `AX:` или попросите «подключись к библиотеке»; ответы ссылаются
  в виде `[code, p. printed, PDF N]` (шифр, печатная страница, страница PDF).
- Свои документы: положите их в папку `inbox` рабочей папки и попросите «AX: разбери мои документы».
- Если что-то не работает: `<command> doctor`, `<command> connect --check`, `<command> debug-report`.

## 9. Если что-то не работает: исправьте сами

Запустите `<command> doctor --json` и `<command> connect --check --json`. Каждая печатает один документ JSON; у
каждого сбоя в нём есть постоянный `code`, `message` и `fix` — команда, которую нужно выполнить (спросите пользователя
перед любой загрузкой или изменением его настроек), после чего запустите обе проверки снова. `ok: true` и `"ok": true`
у каждого приложения означают, что всё готово. Коды:
