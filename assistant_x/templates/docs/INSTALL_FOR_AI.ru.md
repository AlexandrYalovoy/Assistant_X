# Установка Assistant X — инструкция для ИИ-агента

<!-- Made by assistant-x gen-docs from assistant_x/templates/docs/INSTALL_FOR_AI.ru.md: edit that file. -->

Вы — агент (Codex, Claude Code, DeepSeek Harness или другой, который умеет запускать команды), и пользователь попросил
установить или подключить **Assistant X**: локальную библиотеку его документов с поиском по словам и по смыслу, которую
ИИ-приложения получают по MCP. Эта инструкция относится к версии {{version}}; устанавливайте всегда **последний
выпуск**: {{latest}}.

## Бюджет токенов: прочтите сначала

Программа с базовым пакетом в десятки ГБ ставится часами. Вручную это стоило агенту 199 вызовов модели и весь лимит
его тарифа; так, как написано здесь, — 10–20:

- Запустите **одну команду** шага 3. Она ставит всё в фоне и сразу возвращается.
- Опрашивайте состояние командой, которую она напечатала, раз в `poll_s` секунд (5–10 минут): ждите одной командой
  оболочки (`timeout /t 600 /nobreak >nul`, `sleep 600`), а не многими короткими ожиданиями.
- **Не** читайте исходный код, журналы и другие документы и не печатайте длинный вывод: каждая команда здесь печатает
  одну строку JSON. Только при ошибке — состояние с `--tail 20`.
- Одно сообщение пользователю на этап (когда меняется `stage`), а не на каждый опрос.
- Не чините руками то, что делает установщик (Python, пути, векторы): при сбое его `error.fix` говорит, что делать, а
  та же команда ещё раз продолжает с места остановки.

## 1. Спросите пользователя один раз

Одно сообщение, затем дождитесь «да»:

- Загрузки: выпуск (≈ 5 МБ), пакеты Python (≈ 1 ГБ; ≈ 3,5 ГБ с CUDA для видеокарты NVIDIA), модели поиска по смыслу
  (≈ 4,5 ГБ, `--models`; без них поиск идёт только по словам).
- Папки: программа и модели — в `%USERPROFILE%\.assistant_x` (на другом диске: `--machine-dir D:\AssistantX`);
  документы — в `Documents\Assistant X` (другая папка: `--workspace "D:\My library"`). Профиль: `general` или
  `oil-gas-ru` (русскоязычный инженер-технолог нефтегазовой отрасли, `--profile oil-gas-ru`).
- Базовый пакет (`.axbase`), если он есть у пользователя: он проверяется целиком, затем ставится (`--base FILE`); на
  диске документов нужно примерно вдвое больше его размера свободного места. «Да» пользователя — согласие на установку.
- Приватность: библиотека остаётся на ПК; страницы, которые модель читает для ответа, уходят поставщику модели
  приложения.

## 2. Последний выпуск

Узнайте тег последнего выпуска (`vX.Y.Z`) на {{latest}} (или через GitHub API
`https://api.github.com/repos/AlexandrYalovoy/Assistant_X/releases/latest`, поле `tag_name`). Из файлов этого выпуска
скачайте `assistant_x-<version>-src.zip` и `SHA256SUMS.txt` (`{{repo}}/releases/download/<tag>/<file>`; `<version>` —
это тег без `v`) и прежде всего проверьте архив: его SHA-256 (`Get-FileHash -Algorithm SHA256 FILE` в Windows,
`sha256sum FILE` в Linux) должен совпасть с указанным в `SHA256SUMS.txt`; если не совпадает, остановитесь и скажите
пользователю. Распакуйте архив в `%USERPROFILE%\.assistant_x\src\<tag>` (Linux: `~/.cache/AssistantX/src/<tag>`), а не
в «Загрузки» или во временную папку: программа продолжает ею пользоваться.

## 3. Одна команда

В этой папке (Windows):

```
Setup.bat --online --yes --json --background --models [--base "E:\base.axbase"] [--workspace "D:\My library"] [--machine-dir "D:\AssistantX"] [--profile oil-gas-ru]
```

В Linux — `python3.11 -m assistant_x.setup.install` с теми же ключами. Setup.bat находит Python 3.11 на ПК или ставит
его для пользователя с python.org (без winget). Ответ — одна строка JSON: `started`, `status` (команда опроса),
`poll_s`, `python_source`, `outlives_the_agent` (`false`: установка закончится вместе с вашей сессией, держите её
открытой до конца). Порядок: окружение, пакеты, модели, разбор документов, подключение (всех найденных приложений),
самопроверка, база (проверка, установка, векторы на видеокарте или процессоре), doctor.

## 4. Опрашивайте до конца

Запускайте команду `status` из шага 3 (после установки также `<command> status --json`). Одна строка: `state`
(`running`, `done`, `failed`), `stage`, `percent`, `eta_min`, `poll_s`, `error` (`code`, `message`, `fix`). Идёт
работа — подождите `poll_s` секунд и опросите снова. Упавший процесс (ПК перезагрузился, сессия закрылась) опрос
запускает заново сам, `restarts` их считает. Сбой — сделайте, что говорит `error.fix`, и запустите команду шага 3
снова:

| `error.code` | Что делать |
| --- | --- |
| `base_choice` | Спросите пользователя, чьи шифры сохранить при совпадении: добавьте `--keep package` или `--keep own`, запустите снова |
| `network` | Антивирус, проверяющий HTTPS, может держать pypi.org, files.pythonhosted.org, download.pytorch.org, huggingface.co: попросите пользователя разрешить их, запустите снова |
| `disk_full` | Попросите пользователя освободить место (или другой диск: `--workspace`, `--machine-dir`), запустите снова |
| `python` | Попросите пользователя поставить Python 3.11 с python.org (для пользователя), запустите снова |
| `base_failed`, `stopped` | Запустите снова: установка продолжится; опять сбой — состояние с `--tail 20`, причину скажите пользователю |
| `died`, `exception` | Запустите снова из терминала пользователя, который останется открытым; опять сбой — `<command> debug-report` |

## 5. Когда готово

`state: done`: перескажите пользователю `problems` простыми словами и выполните `next`. Каждое приложение нужно
перезапустить (Claude Desktop: значок у часов → Quit; DeepSeek Harness и LM Studio перечитывают настройки сами). Для
Claude Desktop нужен ещё навык: `<command> skill`, заархивировать в zip названную папку, загрузить её в Settings →
Capabilities → Skills. Затем расскажите пользователю:

- В любом подключённом приложении: начните сообщение с `AX:` или попросите «подключись к библиотеке» (приложение
  вызывает `library_guide`); ответы ссылаются в виде `[шифр, п. N, табл. N, стр. N, PDF N]`.
- Свои документы: в папку `inbox` рабочей папки, затем «AX: разбери мои документы».
- Если позже что-то не работает: `<command> doctor --json`, `<command> connect --check --json` (у каждого пункта есть
  `fix`).
