# Приложения Assistant X

<!-- Made by assistant-x gen-docs from assistant_x/templates/docs/CLIENTS.ru.md: edit that file. -->

Assistant X открывает свою библиотеку любому приложению, которое понимает MCP. `assistant-x connect APP|auto` пишет
запись в настройки приложения; каждая запись запускает один и тот же stdio-мост, а он говорит с единственным сервисом
библиотеки рабочей папки на 127.0.0.1.

```
app ──stdio──> assistant-x mcp (the bridge) ──HTTP, token──> assistant-x service ──> the library, the models (once)
app ──stdio──> assistant-x mcp ─────────────────────────────┘
```

- **Мост** (`python -m assistant_x.server.bridge`): ничего тяжёлого не загружает, сразу отвечает на рукопожатие,
  незаметно запускает сервис, если тот не работает (и снова, если он пропал), и сам читает токен из служебной папки
  ПК: в настройках приложений нет никаких секретов.
- **Сервис** (`assistant-x service`): один на рабочую папку, модели загружаются один раз (на видеокарту, если она
  есть), каждый запрос — с токеном, принимаются только Host и Origin 127.0.0.1 и localhost; после 30 минут без
  запросов сервис закрывается, и локальная модель снова получает видеопамять.
- **Наборы инструментов**: `all` (все инструменты: разбор, базовые пакеты) или `reader` ({{reader_tools}}).
  `--compact`: описания в одно предложение, не больше 4 результатов поиска, ответы обрезаются на 6 000 символов с
  подсказкой, как получить остальное.
- **Правила для модели**: инструкции сервера при рукопожатии, навык — если у приложения есть папка навыков, и
  инструмент `library_guide` для любого приложения (если приложение не передаёт инструкции или в чате нет навыков):
  фраза «подключись к библиотеке» или ключ «AX:» заставляет модель вызвать его первым.

`--full` даёт приложению все инструменты без компактных ответов, `--reader` — только инструменты чтения, `--compact` —
короткие ответы. Перед изменением рядом с файлом настроек сохраняется его копия (`<name>.backup-<date>`, три
последние), записи и комментарии других программ остаются, повторный `connect` ничего не меняет, а файл, который не
удаётся прочитать, не трогается: команда печатает запись, которую нужно добавить вручную. `assistant-x disconnect APP`
убирает запись и навык (навык, изменённый вручную, остаётся).

`assistant-x connect --list` показывает приложения (найдено, подключено, набор инструментов); `assistant-x connect
--check [APP]` запускает запись каждого подключённого приложения так же, как это делает приложение, проходит
рукопожатие, получает список инструментов и один раз ищет.

## Куда уходит текст

Библиотека и поиск по ней работают на ПК. Страницы, которые модель читает для ответа, уходят создателю этой модели:
Anthropic для Claude, OpenAI для Codex и ChatGPT, DeepSeek для моделей DeepSeek; с локальной моделью в LM Studio (или
в DeepSeek Harness и Codex, направленных на LM Studio) ничего не покидает ПК.

## Codex и ChatGPT

Codex CLI, его расширение для IDE и приложение ChatGPT для компьютера читают один и тот же `~/.codex/config.toml`:
`assistant-x connect codex` подключает их все. На бесплатном тарифе ChatGPT Codex работает только в приложении для
компьютера (CLI и расширению для IDE нужен платный тариф), а при входе он может попросить номер телефона. Codex прячет
инструменты сервера за своим поиском инструментов: инструкции сервера и навык подсказывают модели, как их найти. С
маленькой локальной моделью через LM Studio (`codex --oss`) Codex сам занимает большую часть контекста (16 000 токенов
из 16 384, а при 32 768 — 68 000 входных токенов за ход), и некоторые шаблоны чата не принимают его системные
сообщения: Qwen3.5 в LM Studio отвечает «System message must be at the beginning» (его шаблон выдаёт ошибку на
системное сообщение не в начале); в проверке с моделью 9B даже с исправленным шаблоном Codex так и не добрался до
библиотеки. У облачных моделей приложения этих ограничений нет; собственный чат LM Studio с той же моделью работает
(`assistant-x connect lmstudio`).

## Чего нельзя

Сайты chatgpt.com и chat.deepseek.com не могут запустить программу на ПК, поэтому до библиотеки им не добраться.
