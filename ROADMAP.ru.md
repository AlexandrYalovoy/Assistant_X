# Дорожная карта

Версия 0.5.4 — открытый прототип для Windows и Linux (первой была 0.1) ([CHANGELOG.md](CHANGELOG.ru.md) описывает, что
она умеет). Что сделано и что будет дальше, примерно в таком порядке.

## Сделано в 0.1

- **Библиотека и разбор.** Одна рабочая папка; разбор PDF, DOC/DOCX, PPTX, сканов, DjVu и архивов в тексты с меткой
  каждой страницы PDF, распознавание (OCR) с оценкой распознавания каждой страницы, поиск дубликатов и редакций, скрытый
  текст вырезается из текста для поиска, и о нём сообщается.
- **Карточки как данные.** JSON-карточки, проверяемые по JSON Schema (`schemas/card-1.json`), — единственный источник
  истины; из них создаются каталог и список источников для обновления; полки — единый список для любой библиотеки;
  карточки двуязычные; у текстов собственный формат («AX text 1»), и цитату можно сверить со страницей
  (`verify_quote`).
- **Поиск и MCP-сервер.** Поиск по словам (SQLite FTS5) и по смыслу (bge-m3, FAISS) с переранжированием — на карте
  NVIDIA (CUDA), карте AMD или Intel (DirectML) или на процессоре (int8 ONNX); оглавления книг, изображения страниц,
  предупреждение «Source quality»; изменения библиотеки только через план и его токен подтверждения.
- **Базовые пакеты.** Библиотека (карточки, тексты, база, без личных документов), которую один пользователь
  экспортирует, а другой устанавливает, обновляет или удаляет в своей рабочей папке, объединяя с собственными
  документами; каждый шаг можно возобновить или отменить.
- **Профили и языковые пакеты.** `general` и `oil-gas-ru`; русский и английский пакеты.
- **Установка.** [`Setup.bat`](Setup.bat) и `assistant-x install` (из интернета или с офлайн-носителя, созданного
  командой `assistant-x prepare-media`), `assistant-x doctor`, `assistant-x debug-report`; pip с версиями релиза.
- **Тесты, CI и документация.** Тесты на Windows и Linux в GitHub Actions, wheel релиза собирается из тега;
  [`CONTRIBUTING.md`](CONTRIBUTING.ru.md), [`SECURITY.md`](SECURITY.ru.md), [`CLA.md`](CLA.md); руководства в
  [`docs/`](docs).

## Дальше

1. **Профили для других областей и новые языки.** Профиль — это только знания одной области
   (`assistant_x/profiles/<name>`): синонимы, формулировки навыка. Новые языки — в виде языковых пакетов
   (`assistant_x/lang/<code>`): определение языка текста и проверки скана (доля кириллицы, сбитая кодировка, оценка
   распознавания с двумя стеммерами) знают только русский и английский, и их нужно обобщить для третьего языка.
2. **Карточки.** Контролируемый список тем для каждого профиля, редактирование карточек из чата, миграции при
   расширении схемы карточки, положение цитаты на изображении страницы (её рамки) для подсветки.
3. **Более лёгкая установка.** ONNX Runtime по умолчанию для эмбеддингов и переранжирования, torch только для NVIDIA
   CUDA; установщик для Linux; проверка на macOS.
4. **Документация и инструменты.** Вывод через `logging` и `--json`, руководство по архитектуре, руководство по данным,
   руководство по профилям, пример мини-библиотеки.

Предложения и вопросы приветствуются в виде issues.
