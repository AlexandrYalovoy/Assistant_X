# Assistant X с локальной моделью в LM Studio

Модель в LM Studio работает на вашем ПК: страницы, которые она читает для ответа, никуда не уходят. Сама она ничего
установить не может, поэтому установку делает установщик Assistant X и он же подключает LM Studio; модель только
пользуется библиотекой: ищет, читает страницы и называет документ и страницу.

## Что нужно

- Windows 10 или 11, носитель Assistant X (или его релиз с GitHub или GitFlic).
- [LM Studio](https://lmstudio.ai) с моделью, которая умеет вызывать инструменты, например модель Qwen3 от 8 миллиардов
  параметров; чем больше модель, тем лучше она держится правил библиотеки.
- Память для модели: около 8 ГБ оперативной или видеопамяти для модели на 8 миллиардов параметров в 4 битах, больше для
  крупной, сверх памяти поиска самой библиотеки.

## Установка в три шага

1. Установите LM Studio и сначала скачайте в нём модель (тогда установщик найдёт LM Studio).
2. Запустите `Setup.bat` с носителя (двойной щелчок). Он ставит программу и модели поиска, создаёт библиотеку
   `Documents\Assistant X` и записывает её в настройки LM Studio (`~/.lmstudio/mcp.json`): 8 инструментов для чтения
   с короткими ответами, сделанными для небольших локальных моделей. Если LM Studio он не нашёл, в итоговой сводке
   вместо этого будет ссылка «Add to LM Studio».
3. Откройте LM Studio, начните чат с моделью и включите сервер `assistant-x` среди её инструментов (интеграций).
   Если LM Studio поставили после Assistant X, выполните в терминале

   ```
   assistant-x connect lmstudio --link
   ```

   и откройте ссылку, которую команда напечатает: LM Studio предложит добавить сервер.

## Как спрашивать

Начинайте вопрос с `AX:`, чтобы модель работала с библиотекой:

```
AX: what is the design pressure of a three-phase separator by GOST R 58367?
```

Модель один раз вызывает `library_guide` (правила ответов и полки библиотеки), ищет через `search_library`, читает нужные
страницы через `read_pages` и отвечает со ссылкой `[шифр, с. печатная, PDF N]`. Перед дословной цитатой или числом из
таблицы она проверяет его через `verify_quote`; если сомневаетесь, попросите «проверь цитату». Библиотека в LM Studio
только читает: приём новых документов и пакеты баз делаются через `Setup.bat`, `intake.bat` или приложение со всеми
инструментами (Claude, Codex).

## Пресет для небольших моделей

Небольшая модель лучше держится правил, если они есть в её системном промпте:

```
assistant-x skill --app guide
```

записывает `system-prompt.md` в `Documents\Assistant X\skill`. В LM Studio сделайте пресет модели и вставьте этот текст
в её системный промпт.

## Если что-то не работает

```
assistant-x doctor
assistant-x connect --check lmstudio
```

`doctor` проверяет программу, модели и библиотеку; `connect --check` запускает подключение LM Studio так же, как его
запускает LM Studio, перечисляет инструменты, один раз ищет и говорит, какая часть не работает и что делать. Если модель
отвечает «Library command failed…», запустите `scripts\debug_report.bat` и пришлите отчёт, который он сделает.
