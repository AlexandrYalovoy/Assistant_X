# Приложения Assistant X

<!-- Made by assistant-x gen-docs from assistant_x/templates/docs/CLIENTS.ru.md: edit that file. -->

Assistant X открывает свою библиотеку любому приложению, которое понимает MCP. `assistant-x connect APP|auto` пишет
запись в настройки приложения; каждая запись запускает один и тот же stdio-мост, а он говорит с единственным сервисом
библиотеки рабочей папки на 127.0.0.1.

```
app ──stdio──> assistant-x mcp (the bridge) ──HTTP, token──> assistant-x service ──> the library, the models (once)
app ──stdio──> assistant-x mcp ─────────────────────────────┘
```

- **Мост** (`python -m assistant_x.server.bridge`): ничего тяжёлого не загружает, сразу отвечает на рукопожатие,
  незаметно запускает сервис, если тот не работает (и снова, если он пропал), и сам читает токен из служебной папки
  ПК: в настройках приложений нет никаких секретов.
- **Сервис** (`assistant-x service`): один на рабочую папку, модели загружаются один раз (на видеокарту, если она
  есть), каждый запрос — с токеном, принимаются только Host и Origin 127.0.0.1 и localhost; после 30 минут без
  запросов сервис закрывается, и локальная модель снова получает видеопамять.
- **Наборы инструментов**: `all` (все инструменты: разбор, базовые пакеты) или `reader` (`library_guide`, `search_library`, `read_pages`, `book_map`, `page_image`, `verify_quote`, `document_info`, `list_documents`).
  `--compact`: описания в одно предложение, не больше 4 результатов поиска, ответы обрезаются на 6 000 символов с
  подсказкой, как получить остальное.
- **Правила для модели**: инструкции сервера при рукопожатии, навык — если у приложения есть папка навыков, и
  инструмент `library_guide` для любого приложения (если приложение не передаёт инструкции или в чате нет навыков):
  фраза «подключись к библиотеке» или ключ «AX:» заставляет модель вызвать его первым.

| Приложение | Имя для `connect` | Что записывается | Набор инструментов | Навык |
| --- | --- | --- | --- | --- |
| Claude Desktop | `claude_desktop` | `%APPDATA%\Claude\claude_desktop_config.json` (и папка Microsoft Store), `mcpServers` | all | zip-архив, который загружает пользователь (`assistant-x skill`) |
| Claude Code | `claude_code` | `claude mcp add-json -s user` (`~/.claude.json`) | all | `~/.claude/skills/assistant-x` |
| Codex и приложение ChatGPT для компьютера | `codex` | `~/.codex/config.toml` (`CODEX_HOME`), `[mcp_servers.assistant-x]`, `startup_timeout_sec = 60` | all | `~/.agents/skills/assistant-x` |
| DeepSeek Harness | `dsh` | `~/.dsh/cordis.patch.yml` (`DSH_HOME`): патч `insert` для `@deepseek-ai/dsh-mcp-client`, `serverName: assistant-x` | reader | `~/.dsh/skills/assistant-x` |
| LM Studio | `lmstudio` | `~/.lmstudio/mcp.json`, `mcpServers` | reader, компактный | нет: `library_guide`; `assistant-x skill --app guide` пишет системный промпт для пресета |

`--full` даёт приложению все инструменты без компактных ответов, `--reader` — только инструменты чтения, `--compact` —
короткие ответы. Перед изменением рядом с файлом настроек сохраняется его копия (`<name>.backup-<date>`, три
последние), записи и комментарии других программ остаются, повторный `connect` ничего не меняет, а файл, который не
удаётся прочитать, не трогается: команда печатает запись, которую нужно добавить вручную. `assistant-x disconnect APP`
убирает запись и навык (навык, изменённый вручную, остаётся).

`assistant-x connect --list` показывает приложения (найдено, подключено, набор инструментов); `assistant-x connect
--check [APP]` запускает запись каждого подключённого приложения так же, как это делает приложение, проходит
рукопожатие, получает список инструментов и один раз ищет.

## Куда уходит текст

Библиотека и поиск по ней работают на ПК. Страницы, которые модель читает для ответа, уходят создателю этой модели:
Anthropic для Claude, OpenAI для Codex и ChatGPT, DeepSeek для моделей DeepSeek; с локальной моделью в LM Studio (или
в DeepSeek Harness и Codex, направленных на LM Studio) ничего не покидает ПК.

## Codex и ChatGPT

Codex CLI, его расширение для IDE и приложение ChatGPT для компьютера читают один и тот же `~/.codex/config.toml`:
`assistant-x connect codex` подключает их все. На бесплатном тарифе ChatGPT Codex работает только в приложении для
компьютера (CLI и расширению для IDE нужен платный тариф), а при входе он может попросить номер телефона. Codex прячет
инструменты сервера за своим поиском инструментов: инструкции сервера и навык подсказывают модели, как их найти. С
маленькой локальной моделью через LM Studio (`codex --oss`) Codex сам занимает большую часть контекста (16 000 токенов
из 16 384, а при 32 768 — 68 000 входных токенов за ход), и некоторые шаблоны чата не принимают его системные
сообщения: Qwen3.5 в LM Studio отвечает «System message must be at the beginning» (его шаблон выдаёт ошибку на
системное сообщение не в начале); в проверке с моделью 9B даже с исправленным шаблоном Codex так и не добрался до
библиотеки. У облачных моделей приложения этих ограничений нет; собственный чат LM Studio с той же моделью работает
(`assistant-x connect lmstudio`).

## Если что-то не работает

`assistant-x doctor --json` и `assistant-x connect --check --json` называют каждый известный сбой постоянным кодом и
командой, которая его исправляет (одна и та же таблица, core/problems.py):

| Код | Что это значит | Как исправить |
| --- | --- | --- |
| `workspace-missing` | Рабочая папка библиотеки ещё не создана. | assistant-x init "{workspace}" |
| `folder-missing` | Не хватает папки рабочей папки. | assistant-x init "{workspace}" |
| `base-missing` | В библиотеке есть карточки, но нет поисковой базы. | assistant-x build |
| `model-missing` | Нет смысловой модели: поиск идёт только по словам. | assistant-x download-models (около 4,5 ГБ: сначала спросите пользователя) |
| `vectors-missing` | Фрагменты без векторов находятся только по словам. | assistant-x embed |
| `older-folder` | Старой служебной папкой ПК (до 0.5.1 или приватной копией Claude Desktop из Microsoft Store) может ещё пользоваться приложение, подключённое раньше. | assistant-x connect auto |
| `app-not-connected` | В приложении нет записи Assistant X. | assistant-x connect {app} |
| `models-in-app-package` | Модели ПК лежат в папке приложения из Microsoft Store: удаление или сброс этого приложения удалит их. | закройте приложения библиотеки на минуту (сервис библиотеки тогда остановится) и выполните любую команду assistant-x: она перенесёт модели в служебную папку ПК |
| `app-in-process` | Приложение запускает собственный сервер библиотеки (запись сделана до 0.5): он держит модели и видеокарту отдельно от общего сервиса остальных приложений. | assistant-x connect {app}, затем перезапустите приложение |
| `app-check-failed` | Запись приложения не отвечает на рукопожатие, список инструментов или поиск. | assistant-x connect --check {app} --json; если снова не работает: assistant-x debug-report |
| `search-words-only` | Поиск приложения отвечает только по словам (нет модели или векторов). | assistant-x doctor --json (он назовёт, какой модели или векторов не хватает) |
| `service-not-started` | Сервис библиотеки не запустился. | прочитайте конец журнала сервиса {log}; затем assistant-x doctor --json |
| `gpu-memory-low` | На видеокарте мало свободной памяти: модели поиска и локальная языковая модель тормозят друг друга. | в assistant_x.toml в разделе [search] задайте device = "cpu" (тогда библиотека оставит видеокарту локальной модели) или загрузите локальную модель с меньшим числом параллельных потоков |
| `skill-outdated` | Навык, загруженный в Claude Desktop, старше программы. | assistant-x skill; заархивируйте папку {folder} в zip и загрузите в Claude (Settings, Capabilities, Skills) |
| `tools-hidden` | Приложение прячет инструменты сервера за своим поиском инструментов (Codex). | найдите инструменты по запросу «assistant-x library_guide search_library»; ресурсов у сервера нет |
| `sign-in-limits` | Тариф или вход ограничивают приложение: на бесплатном тарифе ChatGPT Codex работает только в приложении для компьютера, а при входе может попросить номер телефона. | используйте приложение ChatGPT для компьютера или подключите другое приложение: assistant-x connect auto |

## Чего нельзя

Сайты chatgpt.com и chat.deepseek.com не могут запустить программу на ПК, поэтому до библиотеки им не добраться.

## Инструменты (0.5.6)

| Инструмент | Что делает | Набор | Меняет библиотеку |
| --- | --- | --- | --- |
| `library_guide` | Вызывается первым, когда пользователь хочет работать с библиотекой (подключиться к библиотеке или базе знаний, ключ «AX:»): правила ответов (искать, читать, ссылаться на шифр и страницу, проверять цитаты) и полки этой библиотеки. | reader | нет |
| `search_library` | Найти фрагменты библиотеки по вопросу (по словам и по смыслу). | reader | нет |
| `read_pages` | Текст страниц документа или его части (шифр E-00006-02; номера страниц PDF), не больше 15 страниц за раз: ровно так, как он лежит в библиотеке. | reader | нет |
| `book_map` | Карта документа: оглавление с диапазонами страниц PDF; с номером страницы — часть оглавления вокруг неё и какие таблицы, рисунки, формулы и приложения лежат в её разделе. | reader | нет |
| `page_image` | Изображение страницы оригинала (номер страницы PDF), чтобы проверить рисунки, таблицы, формулы и графики. | reader | нет |
| `verify_quote` | Проверить цитату перед дословным цитированием или число из таблицы: есть ли этот текст на указанной странице PDF документа (или на соседней)? | reader | нет |
| `document_info` | Карточка документа: обозначение, название, авторы, год, тип и полка, область применения, аннотация, темы, ключевые слова, термины, таблицы, ссылки, другие редакции, нумерация страниц. | reader | нет |
| `list_documents` | Список документов библиотеки с фильтрами; текст ищется в названиях, обозначениях и темах. | reader | нет |

| `intake_status` | Ход разбора, переноса в библиотеку и пересчёта базы и следующий шаг — коротким ответом. | all | нет |
| `intake_card` | Черновики карточек обработанных файлов (T0001…): страницы, оценка распознавания, полка, обозначение, название; с tids — ещё заголовки и начало текста. | all | нет |
| `intake_save_meta` | Сохранить строки meta.jsonl пакета разбора (карточки, части, дубликаты, отклонённые) и проверить их. | all | пишет только свои рабочие файлы |
| `intake_apply` | Собрать карточки и перенести документы в библиотеку. | all | да, после «да» пользователя на план |
